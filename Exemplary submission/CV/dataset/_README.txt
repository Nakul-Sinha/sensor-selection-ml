Dataset binaries are NOT downloadable from this Shipd docs example page.
The Dataset tab lists (in prose) the challenge file structure:
  public/train/            - 49 training image patches (.nii.gz)
  public/train_labels/     - 49 corresponding segmentation masks (.nii.gz)
  public/train.csv         - Patient IDs mapped to ground-truth volumes (mm3)
  public/test/             - 10 test image patches (.nii.gz)
  public/sample_submission.csv - Example submission format
  private/answers.csv      - Ground-truth test volumes
The FILE STRUCTURE 'Files' widget on the page shows no downloadable cards for this challenge.
Original source dataset (CC0): Royal Brisbane TOFMRA Intracranial Aneurysm Database,
